# Wordle RU — История разработки

## Обзор проекта

Telegram Mini App — клон игры Wordle на русском языке. Угадай слово из 5 букв за 6 попыток.

**Дата:** 24 января 2026  
**Бот:** @wordlee_ru_bot

---

## Этапы разработки

### 1. Планирование
- Исследование существующих Wordle-клонов в Telegram
- Выбор архитектуры: статический frontend + Python бот
- Определение функционала: daily mode, endless mode, статистика

### 2. Создание структуры
- Папка `webapp/` — фронтенд (HTML, CSS, JS)
- Папка `bot/` — Telegram бот на Python

- HTML структура: игровое поле 6x5, русская клавиатура, модальные окна
- CSS стили: темная тема, анимации flip/shake/bounce

- Подключение telegram-web-app.js

## Проблемы и решения

### Проблема 1: Иконка вопроса не отображалась полностью

**Симптом:** SVG иконка помощи рендерилась без точки внизу.

**Причина:** Отсутствовали атрибуты `stroke-linecap` и `stroke-linejoin`.

**Решение:** Добавлены атрибуты и заменена `<line>` на `<circle>` для точки.

```html
<!-- До -->
<line x1="12" y1="17" x2="12.01" y2="17"></line>

<!-- После -->
<circle cx="12" cy="17" r="0.5" fill="currentColor"/>
```

---

### Проблема 2: Слова не отправлялись на проверку

**Симптом:** При нажатии ОК ничего не происходило, игровое поле было пустым.

**Причина:** `WORDS_VALID` был объявлен как `Set`, а код использовал метод `.some()`, который работает только с массивами.

```javascript
// Ошибка — Set не имеет метода .some()
const WORDS_VALID = new Set([...]);
WORDS_VALID.some(w => ...)  // TypeError
```

**Решение:** Изменен `Set` на обычный массив и исправлена функция проверки.

```javascript
// Исправлено
const WORDS_VALID = [...];
const allWords = [...WORDS_TARGET, ...WORDS_VALID];
return allWords.some(w => normalizeWord(w) === normalized);
```

---

### Проблема 3: Игровое поле не создавалось

**Симптом:** Клавиатура отображалась, но сетка 6x5 — нет.

**Причина:** JavaScript ошибка прерывала выполнение `init()` до вызова `createBoard()`.

**Решение:** Добавлена проверка на null для DOM элементов и try-catch для отладки.

```javascript
function createBoard() {
    const board = document.getElementById('board');
    if (!board) return;  // Защита от null
    // ...
}
```

---

### Проблема 4: Некорректные слова в словаре

**Симптом:** Многие слова были обрезаны (не 5 букв).

**Причина:** При генерации словаря слова были усечены.

**Решение:** Полная переработка словаря — только валидные 5-буквенные русские слова.

---

### Проблема 5: Кнопки в модальном окне слипались

**Симптом:** Кнопки "Поделиться" и "Играть ещё" отображались без отступов.

**Причина:** Недостаточный `gap` в CSS и отсутствие `margin`.

**Решение:** Увеличен `gap` до 24px и добавлен `margin: 8px 0` на кнопки.

```css
.share-section {
    gap: 24px;
}
.share-btn, .play-again-btn {
    margin: 8px 0;
}
```

## Ключевые решения

1. **Vanilla JS** — без фреймворков для простоты и скорости
2. **localStorage** — хранение статистики и состояния игры
3. **Темная тема** — принудительно для единообразия
4. **Бесконечный режим** — для replayability после daily игры
5. **GitHub Pages** — бесплатный хостинг для статики

## Выводы

1. При работе с DOM всегда проверять элементы на null
2. Set и Array имеют разные методы — важно не путать
3. CSS gap + margin дают предсказуемые отступы
4. Telegram Mini Apps требуют HTTPS (кроме localhost)
5. Темная тема должна быть задана явно для консистентности
