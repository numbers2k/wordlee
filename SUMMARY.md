## Хронология проблем и решений

### 1. SVG иконка без точки
**Проблема:** Иконка вопроса рендерилась без точки внизу.  
**Решение:** Заменил `<line>` на `<circle cx="12" cy="17" r="0.5" fill="currentColor"/>`.

### 2. Set vs Array
**Проблема:** `WORDS_VALID.some()` выдавал ошибку — Set не имеет метода `.some()`.  
**Решение:** Заменил Set на обычный массив.

### 3. Игровое поле не создавалось
**Проблема:** JavaScript ошибка прерывала инициализацию.  
**Решение:** Добавил null-проверки для всех DOM элементов.

### 4. Кнопки модалки слипались
**Проблема:** Недостаточный отступ между кнопками.  
**Решение:** Увеличил CSS gap до 24px.

### 5. Разные режимы открытия приложения
**Проблема:** Через кнопку клавиатуры открывалось в компактном режиме, через страницу бота — fullscreen, но шапка перекрывалась UI Telegram.  
**Решение:** Добавил `requestFullscreen()` (API 8.0+) и динамическую обработку `safeAreaInset` / `contentSafeAreaInset`.

### 6. Клавиатура выезжала за края экрана
**Проблема:** На маленьких iPhone кнопки выходили за границы.  
**Решение:** Переработал клавиатуру в iOS-стиле с flex-layout и media queries для всех размеров экранов.

### 7. Не видно первую/последнюю строку на iPhone 14 Pro
**Проблема:** Игровое поле обрезалось сверху и снизу.  
**Решение:** Использовал `100dvh` вместо `100vh` и CSS переменные для safe areas.

### 8. Прогресс игры не сохранялся
**Проблема:** При выходе из приложения игра начиналась заново.  
**Решение:** Автосохранение после каждого действия + события `beforeunload`, `visibilitychange`, `viewportChanged`.

### 9. Не показывалось слово при проигрыше
**Проблема:** Пользователь не узнавал правильный ответ после 6 неудачных попыток.  
**Решение:** Добавил `showLossMessage()` — toast-уведомление и блок в модалке статистики.

### 10. Маленький словарь
**Проблема:** Многие русские слова не принимались.  
**Решение:** Расширил словарь с ~200 до ~1500 слов.

### 11. Сложная логика Daily vs Endless
**Проблема:** Два режима игры создавали путаницу, endless-режим не сохранялся корректно.  
**Решение:** Полностью убрал концепцию ежедневных игр — теперь только бесконечный режим с сохранением.

### 12. 🔴 Утечка токена бота на GitHub
**Проблема:** GitHub Secret Scanning обнаружил токен бота в коде (`bot/bot.py:12`).  
**Решение:**
1. Удалил токен из кода
2. Перешёл на `os.environ['BOT_TOKEN']`
3. Добавил `python-dotenv` для загрузки из `.env`
4. Перегенерировал токен в BotFather
5. Добавил `.env.example` для документации

### 13. Лишний файл vercel.json
**Проблема:** В репозитории был конфиг Vercel, хотя используется GitHub Pages.  
**Решение:** Удалил `vercel.json`.

### 14. Бот выглядел скудно и не реагировал на сообщения
**Проблема:** Бот имел только 3 базовые команды, не отвечал на текст, не работал в группах.  
**Решение:**
1. Добавлены новые команды: `/play`, `/share`, `/about`
2. Улучшены существующие команды с интерактивными кнопками
3. Добавлена поддержка групп с приветствием при добавлении
4. Добавлен умный обработчик текстовых сообщений
5. Добавлена обработка неизвестных команд и inline-кнопок
6. Добавлена глобальная обработка ошибок

### 15. Словарь был плохо реализован (v1.2.0)
**Проблема:** Словарь содержал только ~1,500 слов с множественными числами, склонениями, обрезанными формами. Не было популярных слов, названий стран и городов.  
**Решение:**
1. Интегрирован профессиональный словарь с GitHub (27,083 слов)
2. Добавлены популярные слова: страны, города
3. Словарь разделен на WORDS_TARGET (2,601 слово) и WORDS_VALID (23,939 слов)
4. Всего: 26,540 уникальных пятибуквенных слов
5. Убраны дубликаты, склонения, множественные числа

## Ключевые технические решения

| Решение | Причина |
|---------|---------|
| Vanilla JS | Минимальный размер, быстрая загрузка |
| localStorage | Надёжное хранение без backend |
| CSS Variables | Динамические safe areas от Telegram |
| 100dvh | Корректная высота на мобильных браузерах |
| requestFullscreen() | Полноэкранный режим в Telegram API 8.0+ |
| os.environ | Безопасное хранение секретов |

## Чему научились

1. **DOM** — всегда проверять элементы на null
2. **Set vs Array** — разные методы, нельзя путать
3. **Safe Areas** — критичны для iPhone с Dynamic Island
4. **Autosave** — пользователи ожидают автосохранение всегда
5. **Telegram API 8.0+** — новые методы для fullscreen и safe areas
6. **Media queries** — нужны для каждого размера экрана
7. **Secret scanning** — никогда не коммитить токены в git
8. **User feedback** — находит баги, которые сам не замечаешь
