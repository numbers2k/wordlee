## Геймплей

Угадай слово из **5 букв** за **6 попыток**.

| Цвет | Значение |
|------|----------|
| 🟩 Зелёный | Буква на правильном месте |
| 🟨 Жёлтый | Буква есть, но не на том месте |
| ⬜ Серый | Буквы нет в слове |

## Возможности

- ♾️ **Бесконечный режим** — играй сколько хочешь
- 💾 **Автосохранение** — прогресс не теряется при выходе
- 📊 **Статистика** — отслеживай победы и серии
- 📱 **Адаптивный дизайн** — работает на всех iPhone
- 🌙 **Тёмная тема** — комфортно для глаз
- 📤 **Поделиться** — отправь результат друзьям

## Структура проекта

```
wordlee/
├── docs/               # Frontend (GitHub Pages)
│   ├── index.html      # Разметка
│   ├── styles.css      # Стили + responsive
│   ├── script.js       # Игровая логика
│   └── words.js        # Словарь (36,796 слов)
├── bot/                # Telegram Bot
│   ├── bot.py          # Команды бота
│   ├── requirements.txt
│   └── .env.example
└── README.md
```

## Технологии

- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Backend:** Python, python-telegram-bot
- **API:** Telegram Mini Apps API
- **Хостинг:** GitHub Pages

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню с приветствием |
| `/play` | Быстрый запуск игры |
| `/help` | Подробные правила игры |
| `/stats` | Статистика игрока |
| `/share` | Поделиться с друзьями |
| `/about` | Информация о боте |

## Возможности бота

- Работает в личных чатах и группах
- Интерактивные кнопки в каждом сообщении
- Автоматическое приветствие при добавлении в группу
- Умный ответ на текстовые сообщения
- Обработка неизвестных команд
