## Геймплей

Угадай слово из **5 букв** за **6 попыток**.

| Цвет | Значение |
|------|----------|
| 🟩 Зелёный | Буква на правильном месте |
| 🟨 Жёлтый | Буква есть, но не на том месте |
| ⬜ Серый | Буквы нет в слове |

## Возможности

- ♾️ **Бесконечный режим** — играй сколько хочешь
- 💾 **Автосохранение** — прогресс не теряется при выходе
- 📊 **Статистика** — отслеживай победы и серии
- 🏆 **Система очков** — начисление очков за победы (1000/800/600/400/200/100)
- 🥇 **Лидерборд** — соревнуйся с другими игроками
- 🔄 **Синхронизация** — статистика синхронизируется между устройствами
- 📱 **Адаптивный дизайн** — работает на всех iPhone
- 🌙 **Тёмная тема** — комфортно для глаз
- 📤 **Поделиться** — отправь результат друзьям

## Структура проекта

```
wordlee/
├── docs/               # Frontend (GitHub Pages)
│   ├── index.html      # Разметка
│   ├── styles.css      # Стили + responsive
│   ├── script.js       # Игровая логика
│   └── words.js        # Словарь (24,336 слов)
├── bot/                # Backend (Bot + API)
│   ├── bot.py          # Telegram бот
│   ├── api.py          # REST API сервер
│   ├── database.py     # Работа с PostgreSQL
│   ├── Dockerfile      # Docker конфигурация для бота
│   ├── requirements.txt
│   └── .env.example
├── nixpacks.toml       # Конфигурация сборки
├── railway.json        # Конфигурация Railway
└── README.md
```

## Технологии

- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Backend:** Python, python-telegram-bot, Flask
- **База данных:** PostgreSQL
- **API:** Telegram Mini Apps API, REST API
- **Хостинг:** GitHub Pages (frontend), Railway (backend + БД)

## О проекте

Это мой первый пет-проект, созданный самостоятельно с нуля. Wordlee — русская версия популярной игры Wordle, реализованная как Telegram Mini App.

**Версия:** 1.3.0

### Особенности реализации

- Полностью самостоятельная разработка
- Интеграция Telegram Bot API и Mini Apps
- Backend API с PostgreSQL для синхронизации данных
- Система начисления очков с прогрессией
- Лидерборд с топ-10 игроками
- Профессиональный словарь из 24,336 слов
- Адаптивный дизайн для всех устройств
